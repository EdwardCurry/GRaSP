# GRaSP

This repository contains the code used in the paper "Inferring Gene Regulatory Network from Single-cell Multi-omics Data with Knowledge Guided Sparse Attention".

## File Description

This repository includes the following main files:

*   **`preprocessing.py`**: This Python file contains the code for data preprocessing.
*   **`data_augmentation.py`**: This Python file contains the code used for data augmentation.
*   **`main.py`**: This Python file contains the code for the main model, training, and extracting GRN from the trained model using interpretability components based on Integrated Gradients (IG).
